# Contributing to AJ Series & Aaahhh Fonts Vibe (`v3.1.0`)

Contributions to the public open-ecosystem repositories are welcome.

## What You Can Contribute

1. **Ecosystem and platform adapters** (`distributions/`): packaging, CMS, database, cloud, FinTech and ERP integrations.
2. **Language SDKs** (`distributions/sdks/`): fixes and idiomatic improvements to the public bindings. Keep them zero-dependency and free of secrets.
3. **Keymaps** (`keymaps/`): macOS, Windows, Linux and web input mappings.
4. **Bug and rendering reports** (GitHub Issues). Include:
   - family, style and version (`v3.1.0`);
   - operating system, application or browser, and shaping engine if known;
   - the exact text, language and OpenType features used;
   - a screenshot and the size in px or pt.

## Read-Only Assets

Font binaries, glyph outlines, OpenType tables, family names (`AJ Sahasvi`, `AJ Shresti`, `AJ Talin`, `AJ Anushya`, `Aaahhh Fonts Vibe`), copyright metadata and licence files are the property of **Aravind Jayamohan, India**. Pull requests must not change them. Report glyph or shaping defects as issues.

## Pull Request Checklist

1. Read and agree to [`CLA.md`](./CLA.md).
2. Keep the change focused and describe how you verified it.
3. Do not include email addresses, keys, tokens, account identifiers or local file paths.
4. Use published URLs under `https://fonts.aivibe.cloud` or the `v3.1.0` GitHub release.

## Security

Report vulnerabilities privately as described in [`SECURITY.md`](./SECURITY.md).
