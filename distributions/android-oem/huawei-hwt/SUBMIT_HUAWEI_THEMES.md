# Huawei HarmonyOS / EMUI System Font Publishing Guide

1. Register on **Huawei Developer Console** (https://developer.huawei.com/) and open **Huawei Theme Studio**.
2. Import each `.hwt` archive from this directory (or submit under **Themes › Text Styles**).
3. Approved fonts appear directly inside **Huawei Themes › Text Styles** as selectable System Fonts.
