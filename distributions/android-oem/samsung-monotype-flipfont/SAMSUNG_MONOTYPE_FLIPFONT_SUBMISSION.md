# Samsung Galaxy Store (One UI FlipFont) — Official Publishing Pathway

## Platform Reality
Samsung strictly restricts `Settings › Display › Font size and style` (FlipFont APKs on Galaxy Store) exclusively to **Monotype Imaging** as its sole authorized publisher/packager. Independent developers cannot upload FlipFont APKs directly via Samsung Seller Portal.

## Official Foundry Submission Steps
1. Apply to **Monotype Foundry Partner Program** (MyFonts + Monotype Fonts + Samsung FlipFont licensing): https://www.monotype.com/foundries/partners
2. Submit the compiled flat hinted `.ttf` / `.otf` files from `dist/*/ttf/` & `dist/*/otf/`, visual specimens (`specimens/visual_proofs/`), `trust/CERTIFICATION_REPORT.md` (OTS 156/156, FontBakery 0 FAIL), and `LICENSE.md` proving 100% original ownership by **Aravind Jayamohan, India**.
3. Request **Samsung Galaxy Store FlipFont Distribution** alongside MyFonts & Monotype Enterprise licensing — Monotype compiles the signed FlipFont APKs for One UI so Samsung users download AJ Shresti, AJ Sahasvi, AJ Anushya & AJ Talin straight into Galaxy System Fonts!
