# Xiaomi HyperOS / MIUI System Font Publishing Guide

All 4 `.mtz` packages in this folder add **AJ Shresti, AJ Sahasvi, AJ Anushya, AJ Talin** directly into **Xiaomi / Redmi / POCO Settings › Display › Font (Themes Store)**.

1. Register at **Xiaomi Global Theme Designer Portal**: https://zhuti.designer.intl.xiaomi.com/
2. Upload each `.mtz` package under **Font** category with IP Ownership proof (`../../LICENSE.md` + `../../trust/CERTIFICATION_REPORT.md`).
3. Once approved, Xiaomi users select the font directly in **Themes › Fonts → Apply System-Wide**.
