# Homebrew Cask Tap: AJ Series Fonts v3.1.0

Installs the notarized `.pkg` into `/Library/Fonts/AJ-Series/`:

```zsh
brew tap aivibe-org/fonts https://github.com/aivibe-org/homebrew-fonts
brew install --cask font-aj-series
```

Direct download: https://github.com/aivibe-org/aj-series-fonts/releases/tag/v3.1.0 · Website: https://fonts.aivibe.cloud
