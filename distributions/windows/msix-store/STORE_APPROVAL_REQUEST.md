# Microsoft Store `windows.sharedFonts` Allowlist Request & Partner Center Guide

## Step 1: Request `windows.sharedFonts` permission (one-time)
Open https://aka.ms/storesupport (App Submission Assistance) and submit:

```
Subject: Publisher Permission Request for windows.sharedFonts Extension (AJ Series Fonts)

Publisher: Aivibe Software Services Private Limited (Chennai, India)
App Name: AJ Series Fonts (AivibeSoftwareServices.AJSeriesFonts)
Reason: We publish 5 original typeface families (AJ Sahasvi, AJ Shresti, AJ Talin, AJ Anushya,
Aaahhh Fonts Vibe; 27 TTF styles) so Windows users can use them in Word, PowerPoint, Excel and desktop apps.
IP Proof: Exclusive IP owner Aravind Jayamohan, India has granted Aivibe Software Services Private Limited
publishing rights (attached LICENSE.md and CERTIFICATION_REPORT.md).
Contact: <PLACEHOLDER: Partner Center account contact>
```

## Step 2: Upload `.msixupload`
Download `AJ-Series-Fonts-v3.1.0-Microsoft-Store.msixupload` from
https://github.com/aivibe-org/aj-series-fonts/releases/tag/v3.1.0 (built by the Windows CI workflow)
and upload it in Microsoft Partner Center. Website: https://fonts.aivibe.cloud
