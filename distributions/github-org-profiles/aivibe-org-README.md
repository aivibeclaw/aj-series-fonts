## Flagship Open-Ecosystem Releases

### 1. [`aj-series-fonts`](https://github.com/aivibe-org/aj-series-fonts) — **AJ Series Enterprise Typefaces v3.0 (5 Families · 27 Styles)**
Handcrafted letter-by-letter across **24+ languages and 14 world script systems** (English, Tamil, Sen Tamil, Hindi, Prathmic Hindi, Sanskrit, Marathi, Telugu, Malayalam, Kannada, Bengali, Punjabi Gurmukhi, Arabic, Urdu, Russian Cyrillic, Chinese, Japanese, Korean Hangul, Thai, Ethiopic Amharic, Bahasa Melayu, Spanish, French, German) with **Default 3D Pressed Mild-Gradient Relief (`COLRv1` + `COLRv0` + `CPAL` + `SVG`)**, high-OCR disambiguation (`9px`–`4K`), unmistakable `Regular (400)` → `SemiBold (600)` → `ExtraBold (800)` hierarchy, and zero-overhead AI metadata indexing:
1. **AJ Sahasvi** — Royal Sculpted Horizon Display Small-Caps (`3` styles)
2. **AJ Shresti** — Precision Enterprise UI & Sub-Heading Sans (`6` styles)
3. **AJ Talin** — Expressive Connected Calligraphic Running Script (`6` styles)
4. **AJ Anushya** — Zero-Stub Ultra-Clarity Reading & Micro-OCR Sans (`6` styles)
5. **Aaahhh Fonts Vibe** — *"Sound of Font"* Acoustic Resonance & Smart Phonetic Typeface (`6` styles)

### 2. [`aaahhh-fonts-vibe`](https://github.com/aivibe-org/aaahhh-fonts-vibe) — **Aaahhh Fonts Vibe ("Sound of Font" Engine & Typeface)**
The world's first tailored **Sound of Font** architecture combining `Aaahhh Fonts Vibe` OpenType `GSUB` phonetic shaping (`ss06`–`ss15` & `:lang:` inline triggers with strict numeric/currency boundary protection: `1` stays `1`, `Rs1` stays `Rs1`, while `1u` / `onnu` / `ondru` become `ஒன்று` and `vanakkam` becomes `வணக்கம்`) with a `<1 ms` Python & TypeScript phonetic, spell/grammar, OS-dictionary fusion, and heading-aware inline ghost-text engine.
