# Security & Intellectual Property Policy

## Supported Versions

| Release | Status |
|:---|:---|
| `v3.1.x` | Supported |
| `< v3.1.0` | Superseded. Upgrade to `v3.1.0` |

## Integrity

- Download only from https://fonts.aivibe.cloud or https://github.com/aivibe-org/aj-series-fonts/releases/download/v3.1.0/.
- Check downloaded files against the published `SHA256SUMS.txt` before installing.
- Fonts contain no network or telemetry code. The public SDK bindings in `distributions/sdks/` have no third-party dependencies and make no network calls.
- Software is provided "as is" under [`LICENSE.md`](./LICENSE.md).

## Reporting a Vulnerability

Open a **private GitHub Security Advisory** on the affected repository, or use the official channels listed at https://www.aivibe.in. Do not post exploit details in public issues.

## Intellectual Property

Report rebranded, modified or resold copies of the fonts through https://www.aivibe.in.
